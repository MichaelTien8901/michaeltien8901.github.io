# Project FX3 Vendor Command
   
   This project implement FX3 vendor command to control the CPLD accessory Board.  To simplify the project, I'll use only
   LED and button to test Vendor Command oputput/input.  We will then use the vendor to control CPLD function.
   
## Hardware

   Cypress FX3 explorer Kit with CPLD accessory Board
   
## Settings
    
    J4(pmode) is closed(USBBoot).
    J5 open
